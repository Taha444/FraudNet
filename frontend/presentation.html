Explainability

SHAP — ليه الموديل قال احتيال؟

إيه هو SHAP؟

بيقول مقدار تأثير كل feature على قرار الموديل:

موجب ▲
دفع ناحية FRAUD
سالب ▼
دفع ناحية SAFE
explainer = shap.TreeExplainer(model)
vals = explainer.shap_values(feature_array)
# vals[i] = تأثير feature i
# موجب = fraud / سالب = safe

في main.py

بيتحمل مرة عند الـ startup — يشتغل مع كل prediction:

# Startup:
explainer = _shap.TreeExplainer(model)

# كل /api/predict:
top8 = sorted(zip(names, vals),
  key=lambda x: abs(x[1]))[:8]
